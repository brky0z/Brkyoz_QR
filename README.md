# 🦁 QR Canavarı Brkyoz_QR

C# ve .NET Framework kullanılarak geliştirilmiş, hepsi bir arada QR Kod yönetim aracı.

## 🚀 Özellikler

* **Resimden Oku:** Bilgisayarındaki kayıtlı resimlerden QR okur.
* **Panodan Oku (Paste & Scan):** `PrintScreen` ile aldığın ekran görüntüsünü tek tıkla okur.
* **Link Algılama:** Okunan QR bir web sitesiyse otomatik tarayıcıda açar.


## 🛠 Kullanılan Teknolojiler

* C#
* Windows Forms (.NET Framework 4.7.2)
* ZXing.Net (Barkod kütüphanesi)
* Visual Studio 2022
